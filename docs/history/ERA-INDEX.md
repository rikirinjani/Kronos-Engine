## Data Provenance

Each era file cites calibration sources. Where real data is used, it is attributed.
Estimates are flagged as `"source": "estimate"`. See individual era files for details.

## Validation

- Every `StrategicWorldState` must pass `ValidateStrategicWorldState()` (see schema)
- Nation IDs must be unique across all eras
- Wars and alliances must reference valid nation IDs
- `population` and `gdp` must be non-negative
- `relations` values must be in range [-100, 100]
