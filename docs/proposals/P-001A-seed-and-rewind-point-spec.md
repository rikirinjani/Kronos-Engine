## 1. Seed — Two-Tier Model

### Tier 1: Simple RNG Seed (immediate — reuse Deers Rock)
```
seed = 42
```
A single integer passed to `createWorld()`. Initializes the mulberry32 PRNG. Same seed = identical trajectory. Same as Deers Rock ADR-008 today. Zero new code.

### Tier 2: Universe ID with Genealogy (future — proposed for Deers Rock too)

```typescript
interface UniverseID {
  id: string;            // "U-2026-0001"
  rngSeed: number;       // 42 — the actual PRNG seed
  parent: string | null; // null for primordial, "U-2026-0000" for branch children
  rewindTick: number | null; // which tick this universe branched from
  intervention: string | null; // description of "what changed"
  created: string;       // ISO timestamp
  label: string;         // "Baseline", "COVID-19 no lockdown", etc.
}
```

**How this feeds back into Deers Rock:**
Deers Rock's `createWorld(50, "db", 42)` currently has no concept of a universe identity. Adding `UniverseID` would let Deers Rock:
- Track which branch an experiment belongs to
- Label experiments ("tsunami_vs_normal", "LOS_240_vs_360")
- Export FHIR bundles tagged with universe ID for traceability
- Keep a genealogy of counterfactual experiments locally

The change is additive: `createWorld` accepts an optional `universeId`, defaults to `U-2026-{Date}`. All existing code continues to work.

## 2. Rewind Point — Unified Interface

Both pre-seeded historical moments AND runtime snapshots share the same type:

```typescript
interface RewindPoint {
  id: string;                     // "RP-2026-0001"
  universeId: string;             // "U-2026-0001"
  tick: number;                   // 0 for pre-seeded, N for runtime
  label: string;                  // "Fall of Rome", "Snapshot at tick 1240"
  origin: "preseeded" | "runtime" | "branch";

  // The full world state at this point
  worldState: WorldState;

  // Deterministic integrity
  stateHash: string;              // SHA-256 of serialized worldState
  rngState: {                     // full PRNG state, not just seed
    seed: number;
    callCount: number;            // how many rng() calls so far
  };

  // Pre-seeded only: data package for historical eras
  historicalContext?: {
    era: string;                  // "ancient" | "medieval" | "early-modern" | "industrial" | "modern" | "contemporary"
    year: number;                 // 476, 1492, 1914, 2020, etc.
    calendarDate: string;         // "0476-09-04"
    dataPackage: StrategicWorldState; // see §3
  };

  // Metadata
  created: string;                // real-world timestamp
  parentRewindPoint?: string;     // if this is a branch root
  tags: string[];                 // ["disaster", "pandemic", "what-if"]
}
```

### Pre-seeded vs Runtime — What's different?

| Aspect | Pre-seeded | Runtime |
|--------|-----------|---------|
| Origin | Authored by hand | Generated by `WorldEngine.step()` |
| tick | Always 0 | Current tick at snapshot time |
| worldState | Loaded from data package | Serialized from live engine |
| historicalContext | Full era data | `undefined` — runtime carries state forward |
| Use | Jump to history point, then branch | Branch from live simulation |

## 3. Strategic World State — Nations, GDP, Borders, Wars

At the strategic scale, a pre-seeded era contains:

```typescript
interface StrategicWorldState {
  year: number;
  label: string;

  // Nations and their attributes
  nations: Nation[];

  // Active conflicts
  wars: War[];

  // Alliances and treaties
  alliances: Alliance[];

  // Global aggregate
  globalState: {
    totalPopulation: number;
    avgTechnologyLevel: number;    // 0-100 scale
    avgHealthOutcome: number;      // life expectancy proxy
    co2Emissions: number;          // annual metric tons
    tradeVolume: number;           // relative index
  };
}

interface Nation {
  id: string;                      // "IDN"
  name: string;                    // "Indonesia"
  region: string;                  // "southeast-asia"
  population: number;
  gdp: number;                     // nominal USD
  territory: {                     // simplified border model
    regionIds: string[];           // references to geographical regions
    capital: string;
  };
  government: "democracy" | "autocracy" | "monarchy" | "theocracy" | "transitional";
  technologyLevel: number;         // 0-100
  militaryPower: number;           // relative index
  healthMetrics: {
    lifeExpectancy: number;
    infantMortality: number;       // per 1000
    hospitalBedsPer1000: number;
    universalCoverage: boolean;
  };
  alliances: string[];             // references to Alliance.id
  wars: string[];                  // active wars
  relations: Map<string, number>;  // diplomatic relations -100 to +100
}

interface War {
  id: string;
  name: string;
  parties: {
    attackers: string[];           // nation IDs
    defenders: string[];
  };
  startYear: number;
  status: "active" | "frozen" | "ended";
  casualties: number;
}

interface Alliance {
  id: string;
  name: string;                    // "NATO", "ASEAN", "Warsaw Pact"
  members: string[];
  formed: number;                  // year
  type: "defense" | "economic" | "political";
  strength: number;                // cohesion metric 0-100
}
```

## 4. How It All Connects

```
Seed = 42
    │
    ▼
Universe "U-2026-0001" (rngSeed=42)
    │
    ├── Pre-seeded Rewind Point at "Contemporary" (tick=0, year=2026)
    │   └── StrategicWorldState loaded: nations, GDP, wars, alliances
    │
    ├── World Engine ticks forward (1 tick = 1 day at world scale)
    │   ├── tick 1: healthcare sector processes patients
    │   ├── tick 5: economy sector updates GDP
    │   ├── tick 10: climate sector emits CO2
    │   └── tick N: Runtime Rewind Point (snapshot of all sectors)
    │
    └── Branch at tick N:
        ├── New Universe "U-2026-0002" (parent="U-2026-0001", rngSeed=42)
        ├── Intervention applied
        └── Divergent timeline
```

## 5. What This Unlocks

| Capability | Prerequisite |
|-----------|-------------|
| Same seed = reproduce any world | Seed (Tier 1) — works today |
| Tag experiments with universe ID | Seed (Tier 2) — small add to Deers Rock |
| Jump to WWII and ask "what if" | Pre-seeded Rewind Point + StrategicWorldState |
| Branch from live simulation | Runtime Rewind Point — same as Deers Rock snapshots |
| Compare outcomes across branches | Universe genealogy + CounterfactualDiff |
| Feed universe/branch identity into Deers Rock | Tier 2 seed — PR welcome |
