## 4. Aliasing Artifact in forkBranch — FIXED

### The Problem (pre-fix)

E4 (fresh worlds) shows **ZERO intervention effect** across all horizons and seeds:
```
E4: horizon=20 seed=42 ...
    sentinelOutput.occupancyRate: base=0.5420 intv=0.5420 Δ=0.0000
    sentinelOutput.icuOccupancyRate: base=0.0357 intv=0.0357 Δ=0.0000
    sentinelOutput.supplyStress: base=0.4918 intv=0.4918 Δ=0.0000
```

All 9 combinations (3 horizons × 3 seeds) show Δ=0.0000. The climate intervention does NOT affect DR sentinel metrics when using fresh worlds.

### The Artifact (pre-fix)

E6 (forkBranch) showed **non-zero intervention effect** (pre-fix):
```
sentinelOutput.occupancyRate: baseline=0.5420 intervention=0.5649 Δ=+0.0229
sentinelOutput.icuOccupancyRate: baseline=0.0357 intervention=0.0714 Δ=+0.0357
sentinelOutput.supplyStress: baseline=0.4918 intervention=0.5195 Δ=+0.0278
```

### Root Cause (pre-fix)

The non-zero effect was a **spurious aliasing artifact**, not a real causal effect:

1. E4 uses fresh worlds for both branches → zero effect (correct)
2. E6 used forkBranch for the intervention branch → non-zero effect (artifact)
3. The aliasing test confirmed forkBranch shared EventQueue and RNG closure between branches
4. When baseline ran first, it advanced the shared RNG and populated the shared queue
5. The intervention branch then started from the post-baseline state, not the checkpoint state
6. This cross-contamination appeared as a non-zero intervention effect

### The Fix

Snapshotable interface added to DR adapter (`__snapshot()`/`__reconstruct()` via closure-based helpers). `extractSnapshot`/`reconstructFromSnapshot` exported from `clone.ts`. `sectorReconstructors` stored on `RewindPoint` and `WorldSnapshot`. All pipeline functions (`rewindToSnapshot`, `createBranchFromPoint`, `forkBranch`) updated to use semantic reconstruction.

### Post-Fix Verification

P1/P2/P3 ALL PASS. All causal trace deltas = 0.0000. Contamination-free branch isolation PROVEN.

### Implications for the Paper

- **The rewind/counterfactual mechanism had a latent aliasing defect** (shared EventQueue and RNG closure between branches after checkpoint restore), **now fixed** via the Snapshotable interface
- **Post-fix verification confirms:** P1/P2/P3 ALL PASS; all causal trace deltas = 0.0000; contamination-free branch isolation PROVEN
- **E4's fresh-worlds design remains the correct approach** for causal inference — it avoids branching entirely
- **E6's forkBranch design is now reliable** after the aliasing fix — branches are contamination-free
- **The DR counterfactual causal effect remains NOT ESTABLISHED** — all post-fix deltas = 0.0000; the climate intervention does not propagate to DR outcomes under current architecture
